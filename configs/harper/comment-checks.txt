# The awk checks that also read source comments, one name per line.
# prose-lint runs each one over the comment shadow of a source file.
# The weirpack build fails when a name here is not an awk check under rules/.
# prose-lint-rs runs the native check of each name on each comment
# region, and its tests fail when a name is not a native check.
#
# A `!<kind>` after a name skips one comment kind: go, py, hcl, yaml,
# hash, slash, or dash. SYNTAXES in tools/prose-lint/src/comments.rs
# gives each extension its kind. ProseSlash skips Go, whose comments
# name import paths with no `package` after them (`the client in
# net/http`).
#
# ProseArrow stays out, because a comment often draws an arrow on
# purpose (`a -> b`).
ProseCapsEmphasis
ProseEmoji
ProseLatinAbbreviation
ProseNumberedReference
ProseOpenList
ProseOverUnder
ProsePluralParen
ProseSentenceLength
ProseSlash !go
